⚙️ Setup Google Sheets Sync

Lakukan sekali untuk sinkronkan data ke Google Sheets — bisa dipantau dari HP/laptop manapun.

1
Buka sheets.google.com → buat spreadsheet baru → beri nama "Sister Laundry & Pet Shop"
2
Klik menu Extensions → Apps Script
3
Hapus semua kode, paste isi file apps_script_warung.gs, Save.
4
Deploy → New deployment → Web App
